> 每一段旅程，都从第一步开始。

今天是 2026 年 5 月 19 日，这是我博客的第一篇文章。

## 为什么开始写博客？

写作是一种思考的方式。当我把脑子里模糊的想法用文字表达出来，它们就变得清晰了。

我开始写博客，有三个原因：

1. **记录成长** — 人的记忆是不可靠的，文字是最好的锚点
2. **整理思路** — 把复杂的事情说清楚，自己才算真正理解了
3. **与人连接** — 也许某天，有人读到这里，发现我们想的是同一件事

## 关于"探知者"这个身份

我给自己取了一个称谓：**探知者**。

不是专家，不是大师，只是一个对世界保持好奇、愿意不断探索的人。

> 探索未知，记录已知，分享所知。

## 这个博客会写什么？

没有固定主题。我想到什么就写什么。大概会有：

- 读书笔记和思考
- 学习新技术的过程
- 对日常生活的观察
- 偶尔的一些代码和工具分享

## 一段代码，作为开始

这个博客本身就是用代码搭建的。这是它背后最核心的一段 JavaScript：

```javascript
// 从 Markdown 文件渲染博客文章
async function loadPost(postName) {
  const response = await fetch(`posts/${postName}.md`);
  const markdown = await response.text();

  // 用 marked.js 把 Markdown 转成 HTML
  document.getElementById('content').innerHTML = marked.parse(markdown);

  console.log('文章加载完成！');
}
```

就这么简单。技术并不神秘，当你真正动手做一件事，你会发现它比想象中更容易上手。
